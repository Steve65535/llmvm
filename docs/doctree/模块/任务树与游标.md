## 状态语义

- `Status` 表示 pending/running/completed/failed/waiting human。
- `WetherTraveled` 表示 cursor 是否已经访问过该节点。
- `WetherFinished` 表示节点已从控制流角度终止。
- `SingleFinished` 仍存在于结构体中，但当前 mark_complete 的核心语义已转向 `Status=Completed`。
- acceptance criteria 替代旧 Loop 类型，Leaf 节点通过 retry budget 和 agentic loop 实现多轮工作。
