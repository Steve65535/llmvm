# 任务树与游标

上级：[[../README|项目总览]]

## 职责

任务树是 LLMVM 的控制流结构。`TaskNode` 保存节点身份、状态、类型、子节点、变量、结构化 handoff、错误处理和人类输入字段。`Cursor` 保存当前执行位置，并提供 DFS 移动能力。

核心文件：

- [pkg/tasknode/tasknode.go](/Users/steve/Desktop/llmvm-rag-exp/pkg/tasknode/tasknode.go:45)：任务节点模型。
- [pkg/cursor/cursor.go](/Users/steve/Desktop/llmvm-rag-exp/pkg/cursor/cursor.go:8)：游标和 traversal 方法。

## `TaskNode`

- 源码：[pkg/tasknode/tasknode.go](/Users/steve/Desktop/llmvm-rag-exp/pkg/tasknode/tasknode.go:45)
- 关键字段：
  - `ID` / `Name` / `Type` / `Status`：节点身份和状态。
  - `Parent` / `Children`：树结构。
  - `Variables`：节点作用域变量。
  - `Goal`、`Summary`、`KeyFacts`、`ArtifactRefs`、`Handoff`：结构化交接。
  - `HumanRequest` / `HumanResponse`：人类输入暂停与恢复。

## `Cursor`

- 源码：[pkg/cursor/cursor.go](/Users/steve/Desktop/llmvm-rag-exp/pkg/cursor/cursor.go:8)
- 作用：保存 `Current`、`Root` 和 loop 栈。
- 代表方法：
  - `MoveDown()`：移动到第一个未完成子节点。
  - `MoveFirstUnfinishedChild()`：寻找第一个未完成子节点。
  - `MoveUp()`：回到父节点。
  - `GetPath()`：返回从 root 到当前节点的 ID 路径。
