## `NodeActivation`

- 源码：[pkg/runtime/activation.go](/Users/steve/Desktop/llmvm-rag-exp/pkg/runtime/activation.go:23)
- 字段：`NodeID`、`HierarchyPath`、`ParentGoal`、`SiblingHandoffs`、`ArtifactIndex`、`OpenQuestions`、`WorkingContext`。

## `buildNodeActivation(current *tasknode.TaskNode) NodeActivation`

- 源码：[pkg/runtime/activation.go](/Users/steve/Desktop/llmvm-rag-exp/pkg/runtime/activation.go:35)
- 参数：当前任务节点。
- 返回：`NodeActivation`。
- 作用：确定性构建节点激活上下文，不额外调用 LLM。
- 数据来源：
  - SQLite `QueryAncestorChain` / AST 回退。
  - 父节点 `Goal` 或 `Information`。
  - SQLite `QuerySiblingHandoffs` / AST 回退。
  - SQLite pinned/recent artifacts / artifact store 回退。
