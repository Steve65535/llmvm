## 职责

运行时引擎位于 `pkg/runtime/`，是 LLMVM 的核心调度层。它负责维护当前节点、构建 prompt、调用 LLM、解析 action、执行工具、同步 artifact 和 SQLite memory，并决定 DFS 游标下一步移动。

核心文件：

- [pkg/runtime/runtime.go](/Users/steve/Desktop/llmvm-rag-exp/pkg/runtime/runtime.go:66)：`Runtime` 结构、主执行循环、prompt 构造、action 分发和状态同步。
- [pkg/runtime/activation.go](/Users/steve/Desktop/llmvm-rag-exp/pkg/runtime/activation.go:23)：节点激活上下文。
- [pkg/runtime/actions.go](/Users/steve/Desktop/llmvm-rag-exp/pkg/runtime/actions.go:18)：human-in-the-loop、append sibling、query memory。
- [pkg/runtime/agentic_loop.go](/Users/steve/Desktop/llmvm-rag-exp/pkg/runtime/agentic_loop.go:11)：Leaf 节点的 agentic loop 辅助逻辑。

## 关键设计

- `Runtime.Execute` 是主循环，按 DFS 遍历节点，直到 cursor 完成。
- prompt 构建前会加入 global context 和 node activation 信息。
- LLM 输出必须是 `llm.Response` 中的 action 数组。
- 文件工具动作需要经过 sandbox 路径检查。
- `ErrWaitingHuman` 是暂停执行、等待人类输入的哨兵错误。
- SQLite memory 不取代 AST；它是 runtime 同步出的检索索引。
