# 运行时引擎

上级：[[../README|项目总览]]

`pkg/runtime` 是 LLMVM 的核心执行层。它把当前 TaskNode 转换成 position-aware prompt，调用 LLM，解析 action，再把 action 的副作用提交到任务树、artifact store、SQLite memory 和 vector store。

## 当前实现特征

- 执行模型仍是串行 cursor 驱动。
- 单次 node turn 已被抽到 `runNodeTurn`，并由 goroutine 包裹，用于 timeout 和 panic 隔离。
- Leaf 节点通过 `HandleLeafAgenticLoop` 留在当前节点继续迭代，直到 `mark_complete` 或失败终止。
- `execute_command` 现在把非零 exit 作为 observation 写入 artifact/history，而不是直接让 action 失败。
