## 前端测试与构建

前端没有专门测试脚本，主要使用 lint 和 build：

```bash
cd visualizer/frontend
npm run lint
npm run build
```

## 环境变量

- `DEEPSEEK_API_KEY`：真实 LLM API key。缺失时 CLI 会使用 `StubEngine`。
- `CONTEXT_BUDGET`：总上下文 token 预算，默认 `64000`。

## 保存文件

`--save state.json` 会同时派生 SQLite 文件：

```text
state.json
state.sqlite
```

加载 JSON 状态后，runtime 会尝试从 AST 和 artifact store 重建 SQLite index，避免索引陈旧。

## 注意事项

- 不要提交 `.env` 或 API key。
- 保存状态可能包含任务文本、文件路径和命令输出摘要。
- `test/sandbox/.artifacts` 可能保存大 artifact 的 spill 文件。
